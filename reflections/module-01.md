# Module 1 — Reflection

## What I did

Ran the system with Docker Compose, drew my own diagram of the five parts, traced `GET /users` from the frontend to the `"User"` table, and looked for gaps in the docs.

## What I did not understand at first

How port forwarding works (host port vs container port, e.g. `8082:80`), and that containers find each other by service name (`database`) through Docker's DNS. I did not understand at first the technologies used in services because some of them are new for me. In future they will be subjects for my exploration.

## What I would do differently

Read `module-01.md` fully before starting, so I know every required section up front. Check container logs sooner when something fails. The main thing I would do differently in project is to manage it with one technology either Java, Python or PHP. Also, I would use a framework for SPA frontend. However the choice of such an architecture is explained by the learning purposes.

## How long this took me

Up to 2 hours. The first build took about 7 minutes.
